# Начало работы

## Подготовка Tesseract
Если вам нужен поиск по изображениям, установите Tesseract OCR для Windows:

1. Перейдите на страницу [Tesseract for Windows](https://github.com/UB-Mannheim/tesseract/wiki).
2. Найдите актуальный установщик Windows в разделе `Recent Windows Installer`.
3. Скачайте установщик, например `tesseract-ocr-w64-setup-v5.*.exe`.
4. Установите Tesseract на компьютер.

Если OCR не нужен, программу можно использовать и без Tesseract.

## Первый запуск программы
При первом запуске программа создает файл `config.txt` с базовыми настройками.

После запуска вручную:

1. Введите пароль.
2. Добавьте папки, которые нужно проверять.
3. Выберите нужные расширения файлов.
4. Введите ключевые слова в поле программы.
5. При необходимости включите OCR и настройте остальные параметры.
6. Нажмите `Начать поиск` хотя бы один раз.

Это важно: после первого ручного запуска программа сохранит текущую конфигурацию, и именно ее будет использовать автоматическая проверка.

## Что делает программа после запуска
При ручном запуске программа:

1. Загружает настройки из `config.txt`.
2. Берет список выбранных директорий.
3. Проверяет только отмеченные типы файлов.
4. Ищет введенные ключевые слова.
5. Показывает прогресс и найденные совпадения в интерфейсе.
6. Сохраняет результаты проверки в текстовые отчеты.

## Автоматическая еженедельная проверка
Автоматическая проверка уже настраивается программой сама.

После этого логика работы такая:

1. При входе в Windows программа может запускаться автоматически в скрытом режиме.
2. Дополнительно настроена ежедневная проверка по расписанию.
3. Реальный поиск запускается только если с последней успешной проверки прошло 7 дней или больше.
4. Если компьютер был выключен в день проверки, программа выполнит проверку после следующего включения и входа в Windows.

Пользователю не нужно каждый раз запускать поиск вручную. Достаточно один раз настроить программу.

## Где искать результаты
Все результаты складываются на рабочий стол в папку:

`Результаты_проверки`

Внутри нее программа создает папку с датой в формате:

`dd-mm-yyyy`

В этой папке создаются `.txt`-файлы с именами проверенных директорий:

- `Документы.txt`
- `Отчеты.txt`
- `Архив.txt`

Если в конкретной директории ничего не найдено, в соответствующем `.txt` файле будет запись:

`Совпадения не найдены.`

## Что нужно сделать для автоматической проверки
Чтобы автоматическая проверка работала корректно, достаточно:

1. Один раз вручную открыть программу.
2. Добавить нужные директории.
3. Указать ключевые слова.
4. Выбрать нужные типы файлов.
5. Запустить поиск вручную хотя бы один раз.

После этого программа сможет выполнять еженедельную проверку автоматически.

## Ограничения
Некоторые форматы файлов требуют дополнительных библиотек. Если они не установлены, программа будет работать, но часть форматов может быть недоступна, например:

- PDF
- DOCX
- Excel
- `7z`
- `RAR`
- OCR по изображениям
